# Applied Physics Challenge 2026 – Web Simulation

เว็บจำลองสถานการณ์ (Static Web App ไม่ต้องติดตั้ง Node/Python หรือ Build ใด ๆ) สำหรับการแข่งขัน **Applied Physics - Engineering Application Challenge 2026** ใช้นำเสนอหลักการทางฟิสิกส์ 3 ช่วง (ส่วนที่ 1: 30 คะแนน) และจำลองการทำงานของปุ่มกด 4 ปุ่ม + Web Browser Dashboard สำหรับบอร์ด Arduino UNO Q (ส่วนที่ 2: 80 คะแนน)

---

## 1. วิธีเปิดใช้งานในเครื่อง (Offline)

1. เปิดโฟลเดอร์โปรเจกต์ `physics-challenge-sim`
2. ดับเบิลคลิกไฟล์ `index.html` เพื่อเปิดด้วย Google Chrome / Microsoft Edge ได้ทันที (รองรับการทำงานแบบ `file://` ไม่ต้องต่ออินเทอร์เน็ต)
3. หากต้องการดูผลชุดทดสอบสมการฟิสิกส์ สามารถดับเบิลคลิกเปิดไฟล์ `tests/test.html` ได้เช่นกัน

---

## 2. วิธีนำขึ้น GitHub Pages (เข้าใช้งานผ่านลิงก์เว็บ)

1. สร้าง Repository ใหม่บน GitHub (เช่น `physics-challenge-sim-2026`) แบบ Public
2. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ (`index.html`, `styles.css`, `physics.js`, `app.js`, `README.md`, และโฟลเดอร์ `tests/`) ขึ้นไปที่ branch `main` (รากโฟลเดอร์ `/`)
3. ไปที่แท็บ **Settings** → เมนู **Pages** ทางด้านซ้าย
4. ในหัวข้อ **Build and deployment**:
   - **Source**: เลือก `Deploy from a branch`
   - **Branch**: เลือก `main` และโฟลเดอร์ `/ (root)` แล้วกด **Save**
5. รอประมาณ 1–2 นาที ระบบจะสร้างลิงก์ให้เข้าใช้งานได้ทันทีที่:
   `https://<username>.github.io/<repo>/`

## 4. โมเดลฟิสิกส์ 3 ช่วง

### ช่วงที่ 1: การตกของลูกกลม
- ลูกบิลเลียดหรือลูกเทนนิสวางอยู่บนแท่นสีเทาสูง `30 cm` ด้านหน้า **`อุปกรณ์ผลักลูกกลม`** (กล่องและก้านดันสีฟ้า) ซึ่งดันลูกในแนวราบให้ตกลงจากขอบแท่น `30 cm`
- แผ่นกระดานยาว `48 cm` เริ่มจากฝั่งลูกกอล์ฟแตะพื้น ($\theta_0 = -\arcsin(3 / R_{2,\text{end}})$)
- ความสูงผิวบนของกระดานที่จุดกระทบ: $y_{\text{top}} = 3 - r_1 \sin\theta_0 + t$
- ระยะตกสุทธิ $\Delta h_1 = 30 - y_{\text{top}}$ (หากเลื่อนสามเหลี่ยมไปทางเสาสีเหลืองมากจน $y_{\text{top}} \ge 30\text{ cm}$ จะได้ $\Delta h_1 = 0$) และความเร็วชนจากกฎอนุรักษ์พลังงานกล:
  $$v_1 = \sqrt{2 g \Delta h_1}$$

### ช่วงที่ 2: การกระดกของแผ่นกระดาน
- จุดหมุน (ยอดสามเหลี่ยมสูง `3 cm`) อยู่ที่ $x_p = 25 + d$ โดยสามารถลากทดสอบซ้าย-ขวาได้ตั้งแต่ $d \in [-20, +20]\text{ cm}$ (`+` คือเลื่อนไปทางแท่นสีเทา, `-` คือเลื่อนไปทางเสาสีเหลือง) ส่วนปุ่มคำนวณระยะตามกติกาจะคำนวณในช่วง $d \in [0, 20]\text{ cm}$
- โมเมนต์ความเฉื่อยของกระดานรอบจุดหมุน (ทฤษฎีแกนขนาน):
  $$I_{\text{board}} = \frac{1}{12} M L^2 + M (x_{\text{cm}} - x_p)^2, \qquad I_{\text{sys}} = I_{\text{board}} + m_2 r_2^2$$
- การถ่ายโอนโมเมนตัมเชิงมุมจากลูกกลมที่ตกกระทบเข้าสู่ระบบกระดานและลูกกอล์ฟ (สัมประสิทธิ์การสะท้อน/ถ่ายโอน $e$):
  $$\omega_0 = \frac{(1 + e)\, m_1 v_1 r_1}{I_{\text{board}} + m_2 r_2^2}$$
- **โหมดสมจริง**: อินทิเกรตเชิงตัวเลข ($\Delta t = 10^{-5}\text{ s}$) โดยคิดแรงบิดโน้มถ่วงจากน้ำหนักลูกกอล์ฟและจุดศูนย์กลางมวลกระดานที่เยื้องศูนย์ ($\tau = g \cos\theta\,(M s_{\text{cm}} - m_2 r_2)$) และตรวจการแยกตัวก่อนถึงพื้นหากความเร่งลงของกระดานมากกว่า $g \cos\theta$ จากนั้นคูณตัวประกอบการสูญเสีย $\eta$: $v_2 = \eta\,\omega_{\text{launch}}\,r_2$
- **โหมดอุดมคติ**: ตั้ง $M = 0$, $\eta = 1$, ไม่คิดแรงโน้มถ่วงระหว่างการหมุน ($\omega_{\text{launch}} = \omega_0$)

### ช่วงที่ 3: การลอยตัวของลูกกอล์ฟ
- **โหมดรางบังคับแนวดิ่ง**: ลูกกอล์ฟพุ่งขึ้นตรงตามแนวเสาสีเหลืองด้วยความเร็ว $v_{2y} = v_2 \cos\theta_{\text{launch}}$
- **โหมดลอยอิสระ**: ลูกกอล์ฟหลุดตั้งฉากผิวกระดานด้วยความเร็ว $(v_2 \sin\theta_{\text{launch}},\, v_2 \cos\theta_{\text{launch}})$ เคลื่อนที่แบบโพรเจกไทล์
- ความสูงสูงสุด (เลือกจุดวัดเป็น ขอบล่างลูก / จุดศูนย์กลาง / ขอบบน):
  $$H_{\max} = y_{\text{launch}} + \frac{v_{2y}^2}{2g}$$
